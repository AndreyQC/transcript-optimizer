## Что это за проект

Desktop-приложение для интерактивной оптимизации транскриптов и управления YAML-словарями очистки. Стек: Tauri 2 + React 19 + TypeScript + Vite + Monaco Editor + Zustand + Rust. Саммари генерируется стримом в OpenAI-совместимый API; системный промпт — внешний `.md`-файл.

## Key decisions & constraints

- **Разделение тела и обёртки.** `buildCompactReplacements` отдаёт плотное тело; заголовок/обёртка добавляются только в промпте. Один артефакт — два потребителя (промпт + файл).
- **Источник данных для промпта — store, не диск.** `useDictionaries.getState().entries` синхронно перед `invoke` — актуально, включая несохранённые правки Monaco.
- **`mixReplacements` дефолт true.** Замены влияют на саммари по умолчанию; чекбокс для A/B.
- **Запись компакт-файла не роняет save.** `writeCompactFile` try/catch, ошибка — в строку статуса.
- **Бэклог заведён как сущность.** `-=tasks=-/BACKLOG.md` — единое место отложенных задач.
