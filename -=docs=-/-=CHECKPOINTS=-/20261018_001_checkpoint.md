## Что это за проект

Desktop-приложение transcript-optimizer (Tauri 2 + React 19 + TS + Vite + Monaco +
Zustand + Rust): оптимизация транскриптов, YAML-словари, саммари через
OpenAI-совместимый API. С Phase 10 — ещё и локальная транскрибация видео/аудио
(parakeet-v3 + polyvoice) sidecar-бинарем.

## Architecture map (дельта Phase 10)

| Concern | Path | Note |
|---|---|---|
